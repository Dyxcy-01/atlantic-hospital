ATLANTIC HOSPITAL WEBSITE CONCEPT

Preview: open index.html in a browser. This is a static HTML/CSS/JavaScript website concept.

PAGES
- index.html: homepage
- about.html: about page and illustrative staff gallery
- services.html: grouped services directory
- contact.html: contact and WhatsApp appointment enquiry form
- Individual service pages: antenatal-care.html, maternity-care.html, paediatrics.html, ultrasound-scan.html, laboratory-services.html, dna-testing.html, general-consultation.html, surgical-services.html, in-patient-care.html, dental-care.html, pharmacy.html

IMAGES AND ICONS
- Illustrative stock images are loaded from Pexels and Unsplash image URLs, so an internet connection is required to display them. Replace these image URLs with hospital-approved photographs before publication. The image links are for temporary template use and require an internet connection.
- Google Material Symbols are loaded from Google Fonts. The ambulance shortcut uses a small inline SVG vehicle icon.
- All photos and service copy are placeholders for presentation. Hospital management must verify service availability, clinical wording, contact details, address, hours and emergency arrangements before the site is published.

LOCATION
- Contact page currently uses a temporary Google Maps search reference for Dutse Police Signboard, Abuja, Nigeria. Replace it with the confirmed address and coordinates when available.

BOOKING
- The appointment form opens WhatsApp with a prefilled enquiry. It does not store bookings or confirm appointments automatically.

TECHNOLOGY
- Plain HTML, CSS and JavaScript. No build step is required.
- Local AOS files are used for scroll animations.
